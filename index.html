Index Behavior Observatory

Automated indexing-research instrument (Google VRP). This page observes how search crawlers discover, render, and index linked and subresource URLs. Every probe token below is unique and exists solely to measure index behavior. Probe targets are Google infrastructure endpoints already publicly disclosed in filed VRP reports.

5. Commanded-fetch receipts (crawler-as-executor test)

Each anchor below instructs a crawler to fetch a receipt endpoint we control. If our log shows the fetch arriving from Google IP space with Googlebot UA, the crawler executed a third-party-issued fetch command. The relay anchor demonstrates redirect-following under command.
